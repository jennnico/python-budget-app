# Budget App (Python)

This project was completed as part of the freeCodeCamp Scientific Computing with Python curriculum.

The application allows users to:

- Create budget categories
- Deposit and withdraw funds
- Transfer money between categories
- Print formatted ledgers
- Generate a spending chart showing percentage spent by category

## Concepts Practiced

- Object-oriented programming
- Python classes and methods
- Lists and dictionaries
- String formatting
- Nested loops
- Data visualization using ASCII output
